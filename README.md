# AI Flashcard Generator

Paste any block of text or notes and instantly get a deck of structured, study-ready flashcards — generated by Google's Gemini API and rendered in a clean, flippable card UI.

## Features

- **Instant flashcard generation** — paste raw notes or any topic, get back clean question/answer pairs
- **Adjustable deck size** — choose anywhere from 1 to 30 cards per generation
- **Flip-to-reveal cards** — click a card to flip between question and answer
- **Difficulty regeneration** — reword any individual card as "harder" or "simpler" on demand, without resubmitting your original text
- **Structured, reliable output** — prompt-engineered with explicit JSON schema constraints to keep Gemini's responses consistently formatted
- **Auto-growing input** — the textarea expands as you type, up to a capped height, then scrolls

## Tech Stack

- **React** (via Vite)
- **Tailwind CSS v4**
- **Gemini API** — called directly from the browser (no backend server); structured output enforced via `responseMimeType: "application/json"` and a JSON `responseSchema`

## How It Works

1. Paste text (or a topic) into the input screen and choose how many cards to generate.
2. The app sends your text to Gemini with a schema-constrained prompt, asking for one flashcard per distinct concept or fact.
3. Gemini returns structured JSON, which is parsed directly into flashcard objects — no manual text-parsing or regex cleanup needed.
4. Browse the deck, flip cards to check answers, and regenerate any card as easier or harder without leaving the deck.

## Getting Started

```bash
git clone https://github.com/Aryaman-Singh0912/AI-Flashcard-Generator.git
cd AI-Flashcard-Generator/flashcard-generator
npm install
```

Create a `.env` file inside `flashcard-generator/` with your own Gemini API key:

```
VITE_GEMINI_API_KEY=your_key_here
```

Then run the dev server:

```bash
npm run dev
```

## Note on Architecture

This project calls the Gemini API directly from the browser rather than through a backend server — a deliberate tradeoff for a portfolio project (simpler deployment, no server to maintain). This does mean the API key is visible client-side; not a pattern used for production apps handling sensitive data, but acceptable here.
